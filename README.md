# diamondAI

Flask + Ollama + VRM 으로 만든 아바타 챗봇. 이름은 **다이아**.

말을 하고, 얼굴이 바뀌고, 몸이 움직이고, 만지면 반응한다.
사람과의 사이가 대화에 따라 오르내리고, 그 사이가 말투와 반응을 정한다.

---

## 돌리는 법

```bash
pip install flask requests
python main.py
```

`http://127.0.0.1:5000`

### 따로 넣어야 하는 것

| 파일 | 무엇 |
|---|---|
| `static/avatar.vrm` | 옷 입은 아바타 |
| `static/표현용.vrm` | 맨몸 + 절정 표정용 |

두 파일은 라이선스가 `Redistribution_Prohibited` 라 저장소에 없다.
표현용이 없으면 `avatar.py` 의 `model["layered"]` 를 `False` 로 둔다.

`config.py` 의 `OLLAMA_URL` 과 `OLLAMA_MODEL` 을 쓰는 서버에 맞춘다.

## 짜임새

**하나의 개체가 전부 소유한다.** `avatar.py` 의 `VirtualAvatar` 가
페르소나·표정·동작·관계·만지기·행동을 모두 들고 있고, 화면은
`/api/avatar` 로 그 정의를 받아 쓴다.

원래는 페르소나가 `ai_brain.py` 에, 표정 수치가 `index.html` 에 따로
적혀 있어서 한쪽만 고치면 어긋났다. 그걸 없애려는 구조다.

```
avatar.py          개체. 이 프로젝트의 중심
ai_brain.py        대화 엔진. 표시 추출, 관계 갱신, 고백 판정
memory_manager.py  기억 저장 (memory_store.json)
main.py            Flask 경로
config.py          모델·목소리 설정
templates/         화면
_verify_*.py       검사 스크립트
```

## 무엇이 되는가

### 표정
30종. 그중 11개는 **만화 얼굴** 로, 표정 그룹이 아니라 얼굴 조각
(모프 타깃 57개)을 겹쳐 만들었다 — 눈웃음·째려보기·새침·당황·
눈물 고임·울음·헤벌쭉·시무룩·경악·체념·지그시 보기.

표정마다 **언제 짓는 얼굴인지**(`when`)가 적혀 있고, 그 글은 모델에게도
그대로 건네진다. 그래야 낱말이 안 걸린 문장에서도 스스로 고른다.

모델은 이모지로도, `(표정: 째려보기)` 처럼 이름으로도 얼굴을 고를 수 있다.

**표정 수치는 잠겨 있다.** 사람이 눈으로 보고 맞춘 값이라
`_expressions_locked.json` 에 떠 두고 `_verify_expressions.py` 로 대조한다.

### 동작
13종. 손인사·걷기·고개 젓기·끄덕임·가위바위보 세 손·팔짱·얼굴 가리기·
기지개·등 돌리기·쑥스러워하기.

키프레임은 `_fit_*.py` 가 역기구학으로 풀어 만들었고,
`_verify_collision.py` 가 몸을 뚫지 않는지 20ms 간격으로 검사한다.

**표정과 몸짓의 규칙은 두 줄이다.**
1. 자리가 정한 표정이 이긴다. 동작은 얼굴이 비어 있을 때만 데려온다.
2. 얼굴이 곧 그 동작인 몸짓(쑥스러워하기·얼굴 가리기)만 예외다.

### 관계
10단계. 침묵 → 원수 → 냉랭함 → 서먹함 → 친구 → 가까운 사이 →
사랑 → 집착 → 광기 → 얀데레.

- **바닥(침묵)에서는 모델을 부르지 않는다.** 부르면 무슨 말이든 하게 되어
  '대답하지 않는다' 가 '차갑게 대답한다' 로 변한다
- **광기로 넘어가려면 고백을 주고받아야 한다.** 연인이 아니면 호감이
  229 에서 멈춘다
- **얀데레는 되돌아가지 않는다.** 부정적인 표현이 사라지고, 잠들지 않고,
  대답이 없어도 혼자 말을 잇는다
- **순종** — 호감 상한(660)을 넘어 흘러넘친 점수를 100점당 1 로 모은다.
  50 이 되면 무엇이든 따른다. 얀데레는 유지된다

### 기분
친밀도와 **다른** 0~6칸 상태. 사이가 좋아도 방금 심한 말을 들었으면
상해 있을 수 있다. 쓰다듬으면 풀리고, 3분마다 한 칸씩 저절로 풀린다.

### 만지기
자리 12곳 x 도구 5가지. 판정은 메시 레이캐스트가 아니라 **본에 붙는
보이지 않는 공 63개** 로 한다. 굵기는 그 본이 끌고 다니는 살에서
실제로 재서 만들었다(`_gen_hitboxes.py`).

- 자리마다 허락되는 친밀도가 다르다
- 사이가 깊어지면 같은 자리라도 얼굴과 몸짓이 달라진다
- 옷은 잡아당길 수 있고, 두 번 누르면 벗는다
- 괄호로 쓴 행동(`(머리를 쓰다듬는다)`)도 같은 표를 탄다

### 그 밖
- **목소리** — 브라우저 목소리 기본. `config.py` 에 키를 넣으면
  Gemini TTS(아케르나르)로 바뀐다. 입 모양은 실제 소리 길이에 맞춘다
- **배경** — `static/background/` 에 이미지를 넣으면 깔린다
- **가위바위보** — 손가락 관절로 실제 손 모양을 짓는다
- **먼저 말 걸기 · 잠들기 · 돌아다니기**

## 검사

```bash
python _verify_collision.py     # 동작이 몸을 뚫지 않는지
python _verify_touch.py         # 만지는 자리와 도구가 다 채워졌는지
python _verify_expressions.py   # 표정 수치가 잠근 값 그대로인지
python _verify_pairs.py         # 한 동작에 표정이 하나만 걸리는지
python _verify_stages.py        # 관계 단계의 말투가 어긋나지 않는지
```

표정을 일부러 바꿨다면 `python _verify_expressions.py --잠금` 으로
새 기준을 떠야 한다.

### 판을 가르는 기준

- **표정 수치가 바뀌면** 반드시 `--잠금` 을 다시 하고 그 사실을 적는다
- **관계 눈금이 바뀌면** 저장된 값의 뜻이 달라지므로 크게 적는다
- 검사 스크립트가 하나라도 실패하면 판을 내지 않는다
- **화면을 고쳤으면 `_verify_screen.py` 를 꼭 돌린다.** index.html 은
  스크립트가 한 덩어리라, 한가운데서 오류가 나면 파일 끝의
  `loadAvatar()` 까지 못 가서 아바타가 아예 안 나온다.
  화면은 멀쩡히 뜨고 다이아만 없어서 콘솔을 안 열면 원인이 안 보인다
